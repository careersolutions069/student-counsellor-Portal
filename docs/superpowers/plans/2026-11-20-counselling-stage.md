# Counselling phases and controlled student PDF sharing

Goal — Deliver branch-isolated six-phase counselling, inherited stage files, reusable choice PDFs, post-allotment documents and explicit student sharing.
Architecture — Two new RLS tables reference the student's current branch through cascading composite foreign keys. Counselling state changes and choice reuse run in authenticated manager RPCs under a student lock; file finalization is service-only, rechecks active manager/branch/slot/version and uses immutable 4 MB PDF paths. Student projection includes only shared document IDs, labels and filenames. Viewer RPC rechecks visibility and live student sessions before issuing 60-second URLs. A lazy client workspace keeps each student's forms local and reloads fresh state after actions.

Decisions — Choice PDFs are required before phase outcomes. Grouped stage/security documents are managed separately; missing optional uploads are shown clearly. Only the active phase has outcome actions; past unlocked PDFs remain replaceable. Phase 6 Not Allotted finishes the progression without creating Phase 7. Main allotment freezes progression and enables post-allotment options; each post-allotment letter requires its matching choice PDF. Preferred states remain editable after completion. Reuse creates a hidden snapshot entry, so replacing the original does not change the reused PDF. Replacements preserve slot IDs and reset visibility. Existing signed URLs expire within 60 seconds after hiding; fresh links are denied immediately.
